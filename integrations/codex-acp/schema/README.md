# Codex app-server protocol snapshot

Generated from the locally installed official Codex CLI **0.153.4** using its
`app-server generate-json-schema` command. These are protocol descriptions, not
account/session dumps; no authentication credentials or live messages are included.

Kept as a versioned reference for adapter field names and approval/authentication
contracts. Runtime code does not load these files. Review protocol changes before
refreshing this snapshot.
